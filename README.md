# SkillPath Application

This repository contains the source code for the SkillPath web application, a tool designed to help students assess their skills and build personalized learning roadmaps.

## Getting Started

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   cd skill-navigator-main
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies Used

- Vite
- TypeScript
- React
- Tailwind CSS
- Firebase
- Recharts
